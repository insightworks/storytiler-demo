# Storytiler

Klickbar demo av ett projektverktyg där människor tar en ofärdig idé till ett pågående projekt tillsammans med specialiserade AI-agenter. Gränssnittet är på svenska. Svaren simuleras lokalt. Ingen API-nyckel och ingen extern tjänst behövs.

## Kör

```bash
npm install
npm run dev
```

Öppna adressen som Vite skriver ut, vanligtvis `http://localhost:5173`.

## Flöde

1. Starta från en ofullständig mening, eller klicka ett exempel.
2. Svara Nora i chatten. Briefen uppdateras bredvid. Bekräftat och antagande är visuellt åtskilda. Öppna frågor ligger kvar tills de besvaras.
3. Godkänn briefen. Justera teamet eller lägg till en person.
4. I arbetsytan: projektchatt, aktiviteter, team, brief, översikt. Bjud in specialister, gör en aktivitet av ett meddelande och spara ett beslut.

Det fullt ifyllda projektet är en försäljningsdashboard för säljteamet på Studio Nord. Lansering och ny tjänst startar en egen brief.
